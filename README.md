# ⬗ Steel Oman — موقع مقهى قهوة مختصة

موقع تعريفي بهوية **صناعية داكنة فاخرة** لمقهى **Steel Oman** في السويق، سلطنة عُمان.
عربي بالكامل (RTL)، مبني بـ **React + Vite + Tailwind CSS**.

## المميزات

- 🖤 ثيم صناعي داكن (أسود مطفي + فولاذي + لمسات نحاسية)
- 🔤 خطوط Cairo / Almarai بطابع قوي
- 📱 تصميم متجاوب بالكامل (جوال / تابلت / حاسوب)
- 🧭 الأقسام: البداية، عن المقهى، القائمة، معرض إنستغرام، موقعنا
- ⚙️ قائمة بتفاصيل دقيقة للتحضير اليدوي (جرعات 18g / 25g / 14.2g)
- 📸 شبكة إنستغرام تفاعلية بتراكب عند المرور
- 🗺️ خريطة جوجل مضمّنة لموقع السويق

## نظام الطلب ولوحة الكاشير

- زرّ **«اطلب الآن»** (في الناف بار، الواجهة، والقائمة، وزر عائم) يفتح نافذة طلب:
  **اختيار الطاولة** (أو سفري) → **اختيار الأصناف** بالكميات → **الاسم ورقم الجوال** → **تأكيد**
  مع رقم طلب.
- **لوحة الكاشير:** افتح `‎#/cashier` (أو رابط «دخول الكاشير» أسفل الموقع). تعرض الطلبات
  الواردة لحظيًا مع الطاولة والأصناف والإجمالي وبيانات الزبون، وأزرار لتغيير الحالة
  (جديد → قيد التحضير → جاهز → مكتمل).

### تفعيل المزامنة بين الأجهزة (Firebase)
بدون إعداد، يعمل النظام **محليًا** (طلبات هذا الجهاز/المتصفح فقط — مناسب لجهاز كاشير واحد
أو للتجربة). للمزامنة بين جوال الزبون وجهاز الكاشير:

1. أنشئ مشروعًا مجانيًا في [Firebase Console](https://console.firebase.google.com) وفعّل **Firestore Database**.
2. من *Project settings → Your apps → Web*، انسخ مفاتيح الإعداد.
3. انسخ `.env.example` إلى `.env` واملأ القيم (`VITE_FIREBASE_*`).
4. أعد التشغيل/البناء — سيتحوّل النظام تلقائيًا إلى Firestore.
5. قواعد Firestore المقترحة (مجموعة `orders`): اسمح بالإنشاء والقراءة والتحديث على `orders`.

> الصور لا تُعرض في بيئة الاختبار المعزولة بسبب قيود الشبكة، لكنها تعمل طبيعيًا في المتصفح والنشر.

## التشغيل محليًا

```bash
npm install      # تثبيت الاعتماديات
npm run dev      # خادم التطوير (http://localhost:5173)
npm run build    # بناء نسخة الإنتاج في dist/
npm run preview  # معاينة نسخة الإنتاج
```

## تعديل المحتوى

- **روابط الصور وإنستغرام والخريطة والساعات:** `src/data/site.js`
- **قائمة الطعام والأسعار والجرعات:** `src/data/menu.js`
- **الألوان والخطوط:** `tailwind.config.js`
- **أنماط مشتركة (الأزرار/البطاقات):** `src/index.css`

> ملاحظة: أصناف القائمة وأسعارها نموذجية — استبدلها بالحقيقية.
> الصور من Unsplash بالروابط المباشرة المعتمدة.

## النشر (مجانًا)

ابنِ المشروع وانشر مجلد `dist/`:
- **Netlify / Vercel:** أمر البناء `npm run build`، مجلد النشر `dist`.
- **GitHub Pages:** انشر `dist/` على فرع `gh-pages`.
