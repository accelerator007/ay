# ⬗ Steel Oman — موقع مقهى قهوة مختصة

موقع تعريفي بهوية **صناعية داكنة فاخرة** لمقهى **Steel Oman** في السويق، سلطنة عُمان.
عربي بالكامل (RTL)، مبني بـ **React + Vite + Tailwind CSS**.

## المميزات

- 🖤 ثيم صناعي داكن (أسود مطفي + فولاذي + لمسات نحاسية)
- 🔤 خطوط Cairo / Almarai بطابع قوي
- 📱 تصميم متجاوب بالكامل (جوال / تابلت / حاسوب)
- 🧭 الأقسام: البداية، عن المقهى، القائمة، معرض إنستغرام، موقعنا
- ⚙️ قائمة بتفاصيل دقيقة للتحضير اليدوي (جرعات 18g / 25g / 14.2g)
- 📸 شبكة إنستغرام تفاعلية بتراكب عند المرور
- 🗺️ خريطة جوجل مضمّنة لموقع السويق

## التشغيل محليًا

```bash
npm install      # تثبيت الاعتماديات
npm run dev      # خادم التطوير (http://localhost:5173)
npm run build    # بناء نسخة الإنتاج في dist/
npm run preview  # معاينة نسخة الإنتاج
```

## تعديل المحتوى

- **روابط الصور وإنستغرام والخريطة والساعات:** `src/data/site.js`
- **قائمة الطعام والأسعار والجرعات:** `src/data/menu.js`
- **الألوان والخطوط:** `tailwind.config.js`
- **أنماط مشتركة (الأزرار/البطاقات):** `src/index.css`

> ملاحظة: أصناف القائمة وأسعارها نموذجية — استبدلها بالحقيقية.
> الصور من Unsplash بالروابط المباشرة المعتمدة.

## النشر (مجانًا)

ابنِ المشروع وانشر مجلد `dist/`:
- **Netlify / Vercel:** أمر البناء `npm run build`، مجلد النشر `dist`.
- **GitHub Pages:** انشر `dist/` على فرع `gh-pages`.
