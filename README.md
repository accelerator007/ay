# ☕ Steel Café — موقع مقهى ستيل

موقع تعريفي ثنائي اللغة (عربي / إنجليزي) لمقهى **Steel (ستيل)** في صُحَار، عُمان.
مبني بـ **React + Vite + Tailwind CSS**.

## المميزات

- 🌐 ثنائي اللغة مع تبديل فوري بين العربية (RTL) والإنجليزية (LTR)
- 📱 تصميم متجاوب بالكامل (جوال / تابلت / حاسوب)
- ☕ أقسام: الرئيسية، لمحة، المميزات، القائمة، المراجعات، أوقات الزحمة، الموقع
- 📍 خريطة جوجل مضمّنة + أزرار اتصال واتجاهات وإنستغرام
- 🎨 لوحة ألوان دافئة لمقهى

## التشغيل محليًا

```bash
npm install      # تثبيت الاعتماديات
npm run dev      # تشغيل خادم التطوير (http://localhost:5173)
npm run build    # بناء نسخة الإنتاج في مجلد dist/
npm run preview  # معاينة نسخة الإنتاج
```

## تعديل المحتوى

- **النصوص (عربي/إنجليزي):** `src/i18n.js`
- **قائمة الطعام والأسعار:** `src/data/menu.js`
- **المراجعات:** `src/data/reviews.js`
- **الألوان:** `tailwind.config.js`
- **بيانات الاتصال (الهاتف/إنستغرام/الخريطة):** ثابتة في أعلى المكوّنات
  `Hero.jsx` و`LocationHours.jsx` و`Footer.jsx`

> ملاحظة: أصناف القائمة والمراجعات الحالية **نموذجية** — استبدلها بالأصناف
> والأسعار والمراجعات الحقيقية للمقهى.

## النشر (مجانًا)

ابنِ المشروع ثم انشر مجلد `dist/`:

- **Netlify / Vercel:** اربط المستودع واختر أمر البناء `npm run build` ومجلد النشر `dist`.
- **GitHub Pages:** انشر محتويات `dist/` على فرع `gh-pages`.
